# 포켓몬 스플렌더 시뮬레이터

보드게임 **스플렌더**를 포켓몬 테마로 재구성한 웹 브라우저 시뮬레이터입니다. 사용자 1명 + AI 3명이 한 판을 진행하며, 진행 중 각 플레이어의 실시간 승리 확률이 몬테카를로 시뮬레이션으로 갱신됩니다.

## 게임 소개

플레이어는 포켓몬 카드를 획득해 점수를 모으고, 진화 카드로 보너스를 받아 **18점**에 먼저 도달하는 것을 목표로 합니다.

### 행동 (자기 차례에 하나 선택)

| 행동 | 설명 |
|---|---|
| **볼 획득** | 서로 다른 색 3개 또는 같은 색 2개 (공급 ≥ 4일 때) |
| **카드 보관** | 보드 카드 1장을 비공개 예약 (희귀/전설 불가) |
| **더미 보관** | 1·2·3단계 더미 맨 위 카드를 비공개 예약 |
| **카드 획득** | 볼을 비용으로 지불해 카드 획득 (영구 할인) |
| **진화** | 조건 충족 시 즉시 진화 보너스 획득 |

### 승리 조건

어느 플레이어가 **18점 이상** 도달하면 해당 라운드 종료 후:

1. **총점** → 2. **진화 카드 수** → 3. **획득 카드 수** 순으로 순위 결정

### 실시간 승리 확률

매 행동 종료 후 Web Worker에서 몬테카를로 플레이아웃(기본 200회)을 수행해 각 플레이어의 승리 확률을 비동기로 갱신합니다. 메인 스레드를 블록하지 않아 게임 진행이 끊기지 않습니다.

### 단축키

| 키 | 동작 |
|---|---|
| **1 ~ 4** | 해당 번호 플레이어(1 = 나)의 보유 현황 모달 열기 — 같은 키를 다시 누르면 닫힘, 다른 번호를 누르면 그 플레이어로 전환 |
| **Esc** | 열린 모달 닫기 |

보유 현황 모달에는 보유 볼, 색별 보너스·총점수, 획득 카드, 보관 카드가 모두 표시됩니다. 헤더의 승률 바를 클릭해도 같은 모달이 열립니다.

## 프로젝트 구조

```
src/
├── data/          # 90장 카드 + 6종 볼 정적 데이터
├── game/          # 순수 규칙 엔진 (상태, 합법 행동, 적용, 종료)
├── strategy/      # AI 정책 (V_card/V_evolve 평가함수 + 행동 선택)
├── simulator/     # 몬테카를로 승리 확률 + Web Worker
├── ui/            # DOM/CSS 렌더링, 입력 처리, 게임 루프
└── main.ts        # 진입점
```

## 로컬 실행

### 요구사항

- Node.js 18+
- npm 9+

### 설치

```bash
npm install
```

### 개발 서버

```bash
npm run dev
```

브라우저에서 표시된 주소(기본 `http://localhost:5173`)로 접속합니다.

### 테스트

```bash
npm test
```

Vitest로 61개 테스트를 실행합니다 (데이터 무결성, 엔진 규칙, AI 전략, 시뮬레이터, 통합).

### 타입 검사

```bash
npm run typecheck
```

### 빌드

```bash
npm run build
```

`dist/index.html` 단일 파일로 빌드됩니다. 모든 JS·CSS·이미지(61개 PNG)가 인라인으로 포함되어 정적 호스팅만으로 배포 가능합니다.
